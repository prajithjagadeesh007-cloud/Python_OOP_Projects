# Python OOP Projects

Simple beginner-friendly Python programs demonstrating core OOP concepts.

**Author:** PRAJITH J (26BCE1615), VIT Chennai

## Projects

### 1. Inheritance
Animal (parent class) -> Dog and Cat (child classes).
The children reuse the parent's code and override the speak() method.

### 2. Encapsulation
A BankAccount class with a private balance (__balance).
The balance can only be changed using deposit() and withdraw().

### 3. Polymorphism
Rectangle and Circle classes share the same method name area(),
but each calculates it in its own way.

python filename.py
